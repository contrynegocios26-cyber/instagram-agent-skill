# Material bruto

Jogue aqui as fotos e vídeos que chegarem, do jeito que vierem do celular.
Quando um arquivo virar post, ele sai daqui e vai para a pasta do conteúdo:

    python catalogo.py novo reel "cozinha verde" --status producao --midia VID_20261030.mp4

O catálogo lista tudo que ainda está parado aqui, para nada se perder.
